# 软件美化

优化本项目（Hexo 博客管理器 Flutter 应用）的界面视觉与交互。本技能面向
**本仓库**的代码，所有改动必须落到本项目文件并遵循既有架构。

## 前置动作

1. 先读 `lib/theme/app_theme.dart`，确认当前主题如何构建（`ColorScheme.fromSeed`、
   亮/暗两套 `ThemeData`、组件主题集中定义处）。
2. 定位要美化的目标界面文件（`lib/screens/`、`lib/widgets/`、`lib/desktop/`）。
3. 指出当前界面的具体问题（无层级、配色杂乱、间距失衡、组件不统一、
   缺暗色适配、可点击元素无反馈），按严重度排序。

## 核心原则

- **集中式修改优先**：配色、字号、圆角、间距、组件样式一律改
  `app_theme.dart` 里的 `ThemeData` / 组件主题，禁止在每个页面散落硬编码
  颜色字号。页面里已硬编码的样式要收敛到主题层。
- **亮暗两套同步**：`ColorScheme.fromSeed` 的 seed 色改动要同时作用于
  `brightness: light` 与 `dark` 两套主题，避免只改亮色导致暗色错乱。
- **基于语义色**：用 `cs.primary / onPrimary / surface / surfaceContainerHighest /
  error / secondaryContainer` 等语义色，不用硬编码 Hex。
- **可回滚**：改动前提示先建 Git 快照（或 commit），改完验证可构建。

## 美化维度

### 1. 信息架构与布局
- 导航层级 ≤ 3 层，侧栏/顶栏/抽屉职责清晰（参考 `lib/desktop/desktop_shell.dart`
  的导航组织）。
- 8px 栅格基准，区块间距成倍数（8/16/24），留白充足。
- 重要操作显性（FilledButton），次要操作弱化（TextButton/IconButton）。

### 2. 配色体系
- 单一 seed 色 + 语义色完整映射；强调色占比克制（5-10%）。
- 暗色模式：背景用深灰蓝（如 seed 派生的 dark surface）而非纯黑，文字浅灰白，
  卡片色略亮于背景。
- 对比度：正文 ≥ 7:1，辅助文字 ≥ 4.5:1。

### 3. 排版
- 字号阶梯：大标题 22-28 / 标题 18-20 / 正文 14-16 / 辅助 12-13，统一走
  `textTheme`。
- 行高 1.4-1.6，段落间距 8-16px，中文用系统字体栈。

### 4. 组件规范
- 按钮/卡片/输入框/对话框/表格/列表风格统一（改 app_theme.dart 中对应
  `*ThemeData`）。
- 圆角 4/8/12 档一致，阴影 2-4 层有层级。
- 输入框有聚焦/错误态，对话框有明确标题与操作按钮。

### 5. 动效与反馈
- 过渡 150-300ms，缓动曲线，不干扰操作。
- hover/按下/聚焦反馈、加载态/空态/错误态明确提示。

### 6. 易用性
- 触控目标 ≥ 44px，键盘可导航，危险操作二次确认。

## 输出规范

- 每处改动给出：文件路径 + 完整代码片段（可直接应用）。
- 优先给 `app_theme.dart` 的整体改动块，再给页面级收敛改动。
- 改完输出【验收清单】：逐项勾选已落实的美化点。
- 提醒用户运行 `dart format` 并用 CI（push 触发 GitHub Actions）验证构建。
